# Security policy

## Reporting a vulnerability

Please do not open a public issue for a vulnerability. Use
[GitHub's private vulnerability reporting](https://github.com/RohanHarish6/orbit-local-ai/security/advisories/new)
when available, or contact the repository owner privately through GitHub.

Include the affected file or component, reproduction steps, impact, and any
suggested mitigation. Do not include secrets or personal data in a report.

Orbit is local-first, but optional provider escalation can send prompts to a
third-party endpoint configured by the operator. Review provider permissions
and environment variables carefully before enabling it.
